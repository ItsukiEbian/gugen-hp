# Gugen株式会社 コーポレートサイト

サイボウズ型ヘッダー、クベル（Cvel）型ヒーロー、Sansan型のコンポーネント、ソフトバンクグループ型の会社概要で構成した公式サイトです。

## 構成

- ヘッダー: 事業内容 / 会社概要 / ニュース / 採用情報（アーティクル・お客様サポートは置かない）
- ヒーロー: フルブリード動画。直下に経営理念「人は、まだ進化できる。」
- 事業: 具現AX（LPへ） / 任せた / 人間知能意識研究所（研究所サイトへ） / 人材育成事業
- 会社概要: 理念・ビジョン・代表挨拶・カルチャー

## 開発

```bash
python3 build.py
```

静的ファイルを生成します。ローカル確認は任意の静的サーバーで `index.html` を開いてください。
